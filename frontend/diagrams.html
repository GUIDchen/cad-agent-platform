WORKFLOW

图纸生成与审批流程

从参数输入到版本归档，检出锁与审计贯穿全程

创建图纸图号 / 项目
→
参数 / AI 解析尺寸 / 孔 / 材料
→
生成任务inline / external
→
版本 + 预览sha256 / PNG
→
待审批当前版本校验
→
通过 / 驳回审计 + 通知
检出锁：设计员检出后 30 分钟内独占；过期自动释放；他人生成/检入返回 409；管理员可强制检入。
每一步写审计：创建 / 生成 / 上传 / 审批 / 成员变更
通知：mock 文件或企业微信；失败进死信可重试
AI 失败回退规则，不阻塞生成

DATA MODEL

核心数据模型

8 张业务表；版本只追加，审批与审计可追溯

Userid / name / role / active
Projectid / name / owner_id / status
ProjectMemberproject_id / user_id / role
Drawingproject_id / drawing_no / status / current_version_id
Versiondrawing_id / version / file_path / sha256
Jobid / drawing_id / type / status
Approvalversion_id / reviewer_id / status
AuditLogactor_id / action / object / ip / created_at
关系：Project 1–N Drawing；Drawing 1–N Version；Version 1–N Approval
约束：drawing_no 唯一；(drawing_id, version) 唯一；(project_id, user_id) 唯一
索引：project_id / status / created_by / actor_id / action / created_at
